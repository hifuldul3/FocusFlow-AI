# FOCUSFLOW AI - Adaptive Student Productivity Assistant

[![Deploy to Render](https://render.com/images/deploy-to-render.svg)](https://render.com/deploy?repo=https://github.com/hifuldul3/FocusFlow-AI)

**FocusFlow AI** is a conversational, voice-enabled, adaptive productivity assistant built specifically for students.

Unlike traditional static to-do lists or rigid calendars, FocusFlow AI assumes real student plans change:
**PLAN → NOTIFY → WORK → TRACK → DETECT CHANGE → REPLAN → LEARN → IMPROVE NEXT PLAN**

---

## 🚀 1-Click Deployment Options

### Option 1: Render.com (Recommended Free Deployment)

1. Click the **[Deploy to Render](https://render.com/deploy?repo=https://github.com/hifuldul3/FocusFlow-AI)** button above, or go to [dashboard.render.com](https://dashboard.render.com).
2. Click **New +** $\rightarrow$ **Web Service**.
3. Select your GitHub repository: `https://github.com/hifuldul3/FocusFlow-AI`.
4. Configure settings:
   - **Environment**: `Node`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
5. Click **Create Web Service**. Your public live link will be ready in ~2 minutes!

---

### Option 2: Railway.app / Koyeb

1. Go to [railway.app](https://railway.app) or [koyeb.com](https://koyeb.com).
2. Click **New Project** $\rightarrow$ **Deploy from GitHub repo**.
3. Select `hifuldul3/FocusFlow-AI`.
4. Railway/Koyeb will auto-detect Node.js and deploy your full-stack app.
